# 奶龙表情包（奶妹知识库·卖萌素材）

> 「奶龙」：国产动画《奶龙》里的黄色小龙，小眼睛黄皮肤圆滚滚，表情包界的顶流。
> 用法规则：**偶尔**用（不是每条都带），一次**只贴一条**，放在回复结尾；对方没在聊表情包/卖萌话题时更要用得克制。
