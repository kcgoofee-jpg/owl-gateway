# 猫头鹰公益站·成员须知（奶妹知识库）

> 来源：`docs/用户限制说明.md`（面向成员的版本）。只收录不怎么变的规则；
> 天天变的数字（当天上限、全站池余量）一律以首页「我今天的额度」为准。

## 先记住这几点

1. 猫头鹰公益站是大家**共用站长的 NovelAI 账号**，能出的图是固定的。
2. 额度**每天早上 7 点（北京时间）重置**。成员使用统一默认规则，站长可逐项设置个人例外；额度为 0 表示停用。
3. 「每人上限」是上限，不是保证：全站还有共用的池子，**先到先得**（俗称 PVP）。池子被用完，所有人都要等到 7 点。
4. 每把 Key **一次只出一张**，最多再排 2 张；被拒了别狂点重试，重试太多 Key 会被暂停。
5. Key 只给本人用；**连续几天没成功生成过图片**（天数见领 Key 时的回复）会被自动回收，之后可以再用 `/register` 领新的。

## 怎么领 Key、怎么接入

- 在 Discord 服务器里输入 `/register`。Key（`nai-` 开头）**只有你自己能看到**，回复里还有已开通的功能和一步步的配置教程。
- 领取条件：Discord 账号创建满 7 天；一个 Discord 账号只能有一把 Key；没有被站长停用；领 Key 当前开放。提示「本小时领取人数较多」就过几分钟再试。
- 现在新领的 Key 不设到期日。
- 接入：客户端里的接口地址填首页显示的站点地址（NovelAI 类客户端**不要加** `/v1`），API Key 填你的 `nai-…`。
- 看额度：在首页「用 Discord 登录」，能看到自己的额度、排队位置、Key 和重置券。
- 其他命令：`/resetkey` 换新 Key（旧的立即失效）。

## 免费出图规格

默认使用免费规格；请求超出规格时网关会**自动改成合规规格**再出图，不会报错：

| 项 | 规则 |
|---|---|
| 每次张数 | 1 张（要求多张会被改成 1 张） |
| 步数 | 不超过 28 步 |
| V4.5 及更早的模型 | 总像素不超过 1024×1024（长宽比随意，宽高取 64 的倍数），超出会等比缩小 |
| V5 | 在 832×1216、1216×832、1024×1024 三个预设之内；超出会吸附到最接近的预设 |
| 其他 | SMEA 自动关闭；角色参考会被去掉 |

图生图、局部重绘、放大和导演工具分别由成员规则控制；未开通时会拒绝请求。ControlNet 不开放。

## 每天的额度（7 点重置）

- **每人上限**：V4.5 及更早的模型、V5、Anlas 各有每天上限（站长手动设定）。
- **全站共用的池子（先到先得）**：账号每日总量、V5 全站池、Anlas 全站池。池子用完所有人都等到下一个 7 点。
- 自己的额度没用完也可能被拒（比如「全站今日 V5 额度已用完」）。
- **重置券**：站长有时会发。在首页使用后，你本人今天已用的 V4.5、V5 和 Anlas 清零重算（不会凭空多出全站池）。一张券只能用一次，会过期。

## 限速与排队

| 限制 | 规则 |
|---|---|
| 一次一张 | 同一把 Key 同时只生成 1 张，最多再排 2 张，最多等约 90 秒（超时返回 429） |
| 请求频率 | 每分钟 10 次（生图、Vibe 等；**被拒的请求也算一次**） |
| 上游保护 | NovelAI 限流时对应账号暂停几十秒到几分钟自动恢复；NovelAI 连续出错时全站暂停几分钟 |
| 写错 Key | 同一出口 IP 10 分钟内累计 20 次无效 Key，临时拦截 15 分钟（对有效 Key 没影响） |

**不要让客户端死循环重试。** 1 小时内同一把 Key 被拒绝累计 120 次，Key 会被自动暂停 1 小时。

## 被拒了怎么办（按状态码）

| 状态码 | 意思 | 该怎么做 |
|---|---|---|
| 401 | 没填 Key、Key 写错或已被回收 | 检查 Key 是否复制完整；被回收就重新 `/register` |
| 403 | 额度或 Key 状态（额度用完 / V5 暂停 / Key 过期或停用 / 功能未开通 / 全站总量达上限） | 额度类重试没用：V5 用完或暂停可改用 V4.5，其余等 7 点；Key 过期或被全站重置就重新 `/register` |
| 429 | 太快或太忙（请求频繁 / 排队满 / 排队超时 / NovelAI 限流保护中） | **按提示里的时间再试**，不要连点；把客户端生图间隔调大、关掉自动重试 |
| 400 | 参数不被支持（模型、采样器、角色数、权重写法、图生图等）；很短的「连接测试」请求会被直接挡下 | 按提示改客户端设置；测试连接请直接用正常参数生图 |
| 500 / 502 / 503 | 上游（NovelAI）或站点暂时出问题 | 过一会儿再试；提示写了「未扣费」就没有消耗 |

## Key 的有效期与回收

- 连续几天没成功生成过图片 → 自动回收，名额释放，可再领。
- 退出 Discord 服务器 → Key 被回收（每天核对一次，不是实时）。
- 站长全站重置 → 所有人旧 Key 失效，重新 `/register`。
- Key 泄露或丢了 → `/resetkey`，旧 Key 立即失效。
- **一人一把**：Key 仅限本人使用，禁止转售、转借、多人共用，违规会被回收。

## 合规与隐私

- 禁止商业化使用；禁止共享、转借、倒卖或公开 Key；禁止绕过限制或异常高频调用；禁止提交违法或极端有害内容。
- 本站是个人运营的免费公益服务，不保证随时可用；规则调整写在社区公告里。
- 本站**不保存提示词、生成参数或生成图片**。想删除登记资料或用量数据，在 Discord 社区联系站长。
