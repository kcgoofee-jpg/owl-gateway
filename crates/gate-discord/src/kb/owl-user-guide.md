# 猫头鹰公益站·成员须知（奶妹知识库）

> 来源：`docs/用户限制说明.md`（面向成员的版本）。只收录不怎么变的规则；
> 天天变的数字（当天上限、全站池余量）一律以首页「我今天的额度」为准。
> 2026-11-13 按 GitHub 上的成员须知与系统事实清单重写：已删除的闲置回收、拒绝自动暂停不再写进去。

## 先记住这几点

1. 猫头鹰公益站是大家**共用站长的 NovelAI 账号**，能出的图是固定的。
2. 额度**每天早上 7 点（北京时间）重置**。成员使用统一默认规则，站长可逐项设置个人例外；额度为 0 表示停用。
3. 「每人上限」是上限，不是保证：全站还有共用的池子，**先到先得**（俗称 PVP）。池子被用完，所有人都要等到 7 点。
4. 每把 Key **一次只出一张**，最多再排几张以首页为准（默认 2 张）；被拒了别狂点重试，连点只会撞上每分钟次数。
5. Key 只给本人用。不会因为几天没出图就自动删 Key；退群、全站重置或站长手动处理才会动它。

## 怎么领 Key、怎么接入

- 在 Discord 服务器里输入 `/register`。Key（`nai-` 开头）**只有你自己能看到**，回复里还有已开通的功能和一步步的配置教程。
- 领取条件：Discord 账号创建满 7 天；一个 Discord 账号只能有一把 Key；没有被站长停用；领 Key 当前开放。提示「本小时领取人数较多」就过几分钟再试。
- `/register` 的邀请 Key 选项已停用；没有普通 Key 就重新领取，不要往命令里填旧邀请码。
- 现在新领的 Key 不设到期日。
- 接入：客户端里的接口地址填首页显示的站点地址（NovelAI 类客户端**不要加** `/v1`），API Key 填你的 `nai-…`。
- 看额度：在首页「用 Discord 登录」，能看到自己的额度、排队位置和 Key。重置券仅在本人持有可用券时显示，没有券就不会出现入口；不能承诺每个人都有。
- 其他命令：`/resetkey` 换新 Key（旧的立即失效）。

## 免费出图规格

默认使用免费规格；请求超出规格时网关会**自动改成合规规格**再出图，不会报错：

| 项 | 规则 |
|---|---|
| 每次张数 | 1 张（要求多张会被改成 1 张） |
| 步数限制 | 不超过 28 步 |
| V4.5 及更早的模型 | 总像素不超过 1024×1024（长宽比随意，宽高取 64 的倍数），超出会等比缩小 |
| 尺寸限制（V5） | 在 832×1216、1216×832、1024×1024 三个预设之内；超出会吸附到最接近的预设 |
| 其他 | SMEA 自动关闭；角色参考会被去掉 |

图生图、局部重绘、放大和导演工具分别由成员规则控制；未开通时会拒绝请求。ControlNet 不开放。

## 每天的额度（7 点重置）

- **每人上限**：V4.5 及更早的模型、V5、Anlas 各有每天上限（站长手动设定）。
- **全站共用的池子（先到先得）**：账号每日总量、V5 全站池、Anlas 全站池。池子用完所有人都等到下一个 7 点。
- 自己的额度没用完也可能被拒（比如「全站今日 V5 额度已用完」）。
- **重置券**：站长有时会发；没有固定自动领取或赠送规则。券可以指定重置 V4.5、V5、Anlas 中的一项或多项，以券实际列出的范围为准，不是每张券都重置三项。使用不会增加全站共用池。一张券只能用一次，会过期。
- **分享要求**：以当前后台档位与本人实时状态为准，详见「分享要求档位」。只暂停生图，不停用 Key 或移除频道身份组。

## New API 聊天账号、签到和余额

- NovelAI 生图 Key 与 New API 聊天 API key 是两套凭证，两套额度不互通。
- 当前有效 owl 成员登录站点首页后，点头像菜单的 NEW API 区块，可查看本人 New API 用户名、密码并进入 New API；API key、余额、接入设置与签到在 New API 内查看。不要把这些凭证贴到频道或交给别人。
- 用菜单中的账号登录 New API，在「个人资料」页面每日签到。每天签到的奖励范围以本人实时接口和 New API 页面为准，每个账号北京时间自然日仅能领一次，余额可以累计；这不是每天自动发放，也不会每天把原余额清零重置。
- 新账号保留一次性 $5 初始站内额度。重复打开菜单、换浏览器、重登或重新领取 owl Key，不会重复领取初始余额。邀请奖励为零。
- 站内余额只决定本人的使用上限；模型上游仍有全站共用套餐或预算。上游耗尽、到期或渠道停用，即使钱包有钱也不能调用，不能承诺无限可用。
- 当前可用模型以实时查询和客户端模型列表为准。Claude 共享活动额度耗尽后会下架；不能把历史回答里的“可用”当成当前状态。
- 奶妹频道问答走站长的 配置的对话接口，不扣成员 New API 钱包。成员自己在酒馆 / 客户端里用的模型仍走 New API。
- `/quota` 命令已删除。生图额度看 owl 首页，聊天余额与签到看 New API「个人资料」。

## 限速与排队

| 限制 | 规则 |
|---|---|
| 一次一张 | 同一把 Key 同时只生成 1 张，最多再排几张以首页为准（默认 2），最多等约 90 秒（超时返回 429） |
| 请求频率 | 每分钟 10 次（生图、Vibe 等；**被拒的请求也算一次**）。个别 Key 可能不同，以被拒提示为准 |
| 上游保护 | NovelAI 限流时对应账号暂停几十秒到几分钟自动恢复；NovelAI 连续出错时全站暂停几分钟 |
| 写错 Key | 同一出口 IP 10 分钟内累计 20 次无效 Key，临时拦截 15 分钟（对有效 Key 没影响） |

**不要让客户端死循环重试。** 被拒的请求也计入每分钟次数；连点只会先撞上「请求过于频繁」。没有「拒绝满 N 次就自动暂停 Key」。

## 被拒了怎么办（按状态码）

| 状态码 | 意思 | 该怎么做 |
|---|---|---|
| 401 | 没填 Key、Key 写错或已被回收 | 检查 Key 是否复制完整；被回收就重新 `/register` |
| 403 | 额度或 Key 状态（额度用完 / V5 暂停 / 尚未满足当前分享要求 / Key 过期或停用 / 功能未开通 / 全站总量达上限） | 额度类重试没用：V5 用完或暂停可改用 V4.5；需要分享时去指定频道发一张图；其余等 7 点；Key 过期或被全站重置就重新 `/register` |
| 429 | 太快或太忙（请求频繁 / 排队满 / 排队超时 / NovelAI 限流保护中） | **按提示里的时间再试**，不要连点；把客户端生图间隔调大、关掉自动重试 |
| 400 | 参数不被支持（模型、采样器、角色数、权重写法、图生图等）；很短的「连接测试」请求会被直接挡下 | 按提示改客户端设置；测试连接请直接用正常参数生图 |
| 500 / 502 / 503 | 上游或站点暂时出问题 | 过一会儿再试；提示写了「未扣费」就没有消耗 |

## Key 的有效期与回收

- 不会因为几天没出图就自动删 Key（闲置回收已关掉）。站长会定期手动清理。
- 退出 Discord 服务器 → Key 被回收（每天核对一次，不是实时）。
- 站长全站重置 → 所有人旧 Key 失效，重新 `/register`。
- 站长手动停用或删除。
- Key 泄露或丢了 → `/resetkey`，旧 Key 立即失效。
- **一人一把**：Key 仅限本人使用，禁止转售、转借、多人共用，违规会被回收。

## 合规与隐私

- 禁止商业化使用；禁止共享、转借、倒卖或公开 Key；禁止绕过限制或异常高频调用；禁止提交违法或极端有害内容。
- 本站是个人运营的免费公益服务，不保证随时可用；规则调整写在社区公告里。
- 本站**不保存提示词、生成参数或生成图片**。想删除登记资料或用量数据，在 Discord 社区联系站长。


## 分享要求档位

分享规则以后台当前设置和本人实时状态为准：额度档要求昨日用满 V4.5 或 V5 后今日分享；全员档要求除站长与已开通赞助席外的成员每天先分享一次，均按北京时间 07:00 重置。新帖首楼和旧帖补图都可；只暂停生图，不停用 Key 或移除身份组。拿不到当前档位或本人分享状态时不要猜。本人实时数据的 `share_requirement` 给出当前档位、今天是否已分享、本人是否豁免及现在是否需要分享；`share_lock` 给出被拦截的具体原因。

## 奶妹的实时查询与聊天限制

- 排队、出图统计从站点只读接口查询；本人额度、分享要求、钱包、签到状态和已开放模型从本轮实时接口查询。查不到时说明未查到，不猜测、不沿用别人或历史消息中的数字。
- 模型已开放不等于上游额度仍充足，站内钱包余额也不代表共享上游套餐余量。
- 目前没有单用户每日聊天次数上限；同频道一次处理一个问题，短时间重复叫她会受频道节流。频道上下文只保留最近六轮，外接 API 还有共享额度与并发限制。
