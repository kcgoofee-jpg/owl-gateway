# 用户限制说明

> 写给成员：额度怎么算、为什么会被拒、被拒了怎么办。更新日期 2026-10-28。
> 天天在变的数字（今天你的 V4.5 / V5 上限、全站还剩多少）请看首页登录后的「我今天的额度」；这里只写不怎么变的规则。
> 机器人只剩两个命令：`/register` 领 Key、`/resetkey` 换 Key。看额度请用网页登录，机器人不再管额度。

## 先记住这几点

1. 猫头鹰公益站是大家**共用站长的 NovelAI 账号**，能出的图是固定的。
2. 额度**每天早上 7 点（北京时间）重置**。成员使用统一默认规则，站长可逐项设置个人例外；额度为 0 表示停用。
3. 「每人上限」是上限，不是保证：全站还有共用的池子，**先到先得**（俗称 PVP）。池子被用完，所有人都要等到 7 点。
4. 每把 Key **一次只出一张**，最多再排 2 张；被拒了别狂点重试，重试太多 Key 会被暂停。
5. Key 只给本人用；**连续几天没成功生成过图片**（天数见领 Key 时的回复）会被自动回收，之后可以再用 `/register` 领新的。

## 1. 怎么领 Key、怎么接入

- 在 Discord 服务器里输入 `/register`。Key（`nai-` 开头）**只有你自己能看到**，回复里还有已开通的功能和一步步的配置教程。请先保存好。
- 领取条件：Discord 账号创建满 7 天；一个 Discord 账号只能有一把 Key；没有被站长停用；领 Key 当前开放（关闭时看站长公告）。提示「本小时领取人数较多」就过几分钟再试。
- 现在新领的 Key 不设到期日。之前领的 Key 如果首页显示了到期日，到期后再 `/register` 一次就能换新的。
- 站长单独发给你的邀请 Key：`/register` 时把它填进 `key` 选项，会绑定到你的账号，Key 不变，客户端里不用改。邀请凭据遵守相同的开放状态、身份组资格、名额、有效期和闲置回收条件。
- 接入：客户端里的接口地址填首页显示的站点地址（NovelAI 类客户端**不要加** `/v1`），API Key 填你的 `nai-…`。各种客户端的填法见首页的使用说明和领 Key 时的回复。
- 看额度：在首页「用 Discord 登录」，能看到自己的额度、排队位置、Key 和重置券。网页登录会读取 Discord 基本资料、所属服务器和已连接账号；配置了领取身份组时，还会核验相应服务器的成员身份。不读取消息。
- 其他命令：`/resetkey` 换新 Key（旧的立即失效）。
- 已开通功能和额度以你的有效规则为准，站长修改默认规则或个人例外后立即生效。

## 2. 免费规格

默认使用免费出图规格。未单独开通高规格生图时，你的请求如果超出下面的规格，网关会**自动改成合规规格**再出图，不会因此报错：

| 项 | 规则 |
|---|---|
| 每次张数 | 1 张（要求多张会被改成 1 张） |
| 步数 | 不超过 28 步 |
| V4.5 及更早的模型 | 总像素不超过 1024×1024（长宽比随意，宽高取 64 的倍数），超出会等比缩小 |
| V5 | 在 832×1216、1216×832、1024×1024 这三个预设之内；超出会吸附到最接近的预设 |
| 其他 | SMEA 自动关闭；角色参考会被去掉 |

图生图、局部重绘、放大和导演工具分别由成员规则控制；未开通时会拒绝请求。ControlNet 不开放。

## 3. 每天的额度（7 点重置）

各项额度都是**站长手动设置的数**（站长的服务器、账号状况变了就调），具体数字以首页显示为准；这里写的是规则。

### 每人上限

| 类型 | 每人每天 | 说明 |
|---|---|---|
| V4.5 及更早的模型 | 站长手动定的数 | 每天 7 点重置；默认规则统一，个人例外以账户显示为准 |
| V5 | 站长手动定的数 | 另有全站合用的 V5 池（见下）；站长还留了一个「V5 暂停」开关：暂停期间 V5 请求直接被拒（不扣费），首页会显示暂停 |
| Anlas | 站长手动定的数 | 只有 Vibe 用到：编码一张参考图约 2 点；带多张 Vibe 或精确参考的请求会有额外消耗 |

### 全站共用的池子（先到先得）

- **账号每日总量**：每个 NovelAI 账号一天能出的图是站长手动定的数，全站合在一起先到先得。
- **V5 全站池**：每天一个站长手动定的总数，所有人合用。
- **Anlas 全站池**：Vibe 等花 Anlas 的操作共用每天一个全站 Anlas 池。

池子是共用的，所以**你自己的额度没用完也可能被拒**（比如「全站今日 V5 额度已用完」）。池子用完后，所有人等到下一个 7 点。想稳妥一点，就别扎堆在高峰时段抢。

### 重置券

站长有时会发「重置券」。在首页使用后，**你本人**今天已用的 V4.5、V5 和 Anlas 都会清零重新算（不会凭空多出全站池）。一张券只能用一次，会过期。

## 4. 限速与排队

| 限制 | 规则 |
|---|---|
| 一次一张 | 同一把 Key 同时只生成 1 张，最多再排 2 张：排着的等前面的出完才开始，最多等约 90 秒（超时返回 429）；还要再排会被当场退回。每人能排几张站长可以调，以首页显示为准 |
| 请求频率 | 每分钟 10 次（生图、Vibe 等；**被拒的请求也算一次**）。个别 Key 的数值可能不同，被拒提示里会写这把 Key 的上限 |
| 上游保护 | NovelAI 限流时，对应账号会暂停几十秒到几分钟自动恢复；NovelAI 连续出错时全站暂停几分钟自动恢复；每个账号每天的出图总量有上限，用完等 7 点 |
| 写错 Key | 同一个出口 IP 在 10 分钟内累计 20 次无效 Key，会被临时拦截 15 分钟（对有效 Key 没影响） |

## 5. 被拒了怎么办

| 状态码 | 意思 | 该怎么做 |
|---|---|---|
| 401 | 没填 Key，或 Key 写错；Key 已被删除（闲置回收、退群回收）后也是这个提示 | 先检查 Key 是否复制完整；确认已被回收的话，按第 6 节处理 |
| 403 | 额度或 Key 状态。常见提示：「今日 V4.5 额度已用完」「今日 V5 额度已用完」「全站今日 V5 额度已用完」「今日 Anlas 额度不足」「全站今日 Vibe 额度已用完」「V5 暂停」；Key 已过期、已被站长停用、全站重置后已失效、被暂停、功能或模型没给你开通；「本站今日出图总量已达上限」（账号当天的量用完了，等重置也不会变好） | 额度类的重试没用：V5 用完 / 暂停可以改用 V4.5，其余等到 7 点。Key 过期或被全站重置就去 Discord 重新 `/register`；被暂停就等提示里写的恢复时间；其他的联系站长 |
| 429 | 太快或太忙。常见提示：请求过于频繁；「已有 2 张在排队，请等前面完成后再发」；全站排队已满；站点繁忙、排队超时；NovelAI 限流保护中；NovelAI 连续出错、全站暂停出图 | **按提示里写的时间再试**，不要连点。客户端有「生图间隔」或「自动重试」的话，把间隔调大、关掉自动重试和批量生成 |
| 400 | 参数不被支持（模型、采样器、角色数、权重写法、图生图等）；很短很小的「连接测试」请求会被直接挡下（不出图） | 按提示改客户端设置；测试连接请直接用正常参数生图 |
| 500 / 502 / 503 | 上游（NovelAI）或站点暂时出问题，比如「V5 额度暂时无法确认」「上游账号额度不足」 | 过一会儿再试。提示里写了「未扣费」的，就没有产生消耗 |

**不要让客户端死循环重试。** 1 小时内同一把 Key 被拒绝累计 120 次（轻量的拒绝按半次算），Key 会被自动暂停 1 小时（回 403，提示里写着自动恢复的时间）。「排队已满」「排队超时」这类不怪你的拒绝不计入。

## 6. Key 的有效期与回收

| 情况 | 会怎样 |
|---|---|
| Key 设了到期日并且到期 | Key 过期，再用 `/register` 领新的（现在新领的 Key 不设到期日） |
| **连续几天没有成功生成过图片** | Key 被自动回收，名额释放；之后可以再用 `/register` 领新的 Key。天数见领 Key 时的回复；从没生成过图的 Key 从领取那天算起。站长邀请的 Key 不在此列。网关停机维护超过 1 小时的话，计时会从恢复那一刻重新开始 |
| 退出 Discord 服务器 | Key 被回收、名额释放（每天核对一次，不是实时）。重新加入后可以再领 |
| 站长全站重置 | 所有人的旧 Key 失效，用旧 Key 请求会提示去 `/register` 重新领取（邀请 Key 同样失效） |
| 被站长停用 | 提示「该 Key 已被站长停用」，有疑问联系站长 |
| Key 泄露或丢了 | 在 Discord 输入 `/resetkey`，旧 Key 立即失效 |

**一人一把。** Key 仅限本人使用，禁止转售、转借、多人共用，共用或转售会被回收 Key。
