# 用户限制说明

> 写给成员：额度怎么算、为什么会被拒、被拒了怎么办。更新日期 2026-10-15（3.0）。
> 天天在变的数字（今天你的 V4.5 上限、全站每小时上限、全站 V5 还剩多少）请看首页的「我今天的额度」，或在 Discord 里输入 `/quota`；这里只写不怎么变的规则。

## 先记住这几点

1. 猫头鹰公益站是大家**共用站长的一个 NovelAI 账号**，能出的图是固定的。
2. 额度**每天早上 7 点（北京时间）重置**。
3. 「每人上限」是上限，不是保证：全站还有共用的池子，**先到先得**（俗称 PVP）。池子被用完，所有人都要等到 7 点。
4. 每把 Key **一次只出一张**；被拒了别狂点重试，重试太多 Key 会被暂停。
5. Key 只给本人用；**连续 7 天没生成过图**会被回收，之后可以再用 `/register` 领新的。

## 1. 怎么领 Key、怎么接入

- 在 Discord 服务器里输入 `/register`。Key（`nai-` 开头）**只有你自己能看到**，回复里还有已开通的功能和一步步的配置教程。请先保存好。
- 领取条件：Discord 账号创建满 7 天；一个 Discord 账号只能有一把 Key；没有被站长停用；领 Key 当前开放（关闭时看站长公告）。提示「本小时领取人数较多」就过几分钟再试。
- 10 月 15 日起新领的 Key 不设到期日。之前领的 Key 如果首页显示了到期日，到期后再 `/register` 一次就能换新的。
- 站长单独发给你的邀请 Key：`/register` 时把它填进 `key` 选项，会绑定到你的账号，Key 不变，客户端里不用改。
- 接入：客户端里的接口地址填首页显示的站点地址（NovelAI 类客户端**不要加** `/v1`），API Key 填你的 `nai-…`。各种客户端的填法见首页的「使用须知」和领 Key 时的回复。
- 看额度：Discord 里 `/quota`；或者在首页「用 Discord 登录」，能看到自己的额度、排队位置、Key 和重置券。网页登录只申请 Discord 的 identify 权限（认出你是谁），不读你的消息、好友和服务器列表。
- 其他命令：`/resetkey` 换新 Key（旧的立即失效）、`/反馈` 写几句话给站长、`/help` 简要说明。
- 新 Key 默认开通：文生图、标签补全、Vibe（参考图编码，会花 Anlas，见第 3 节）。放大、导演工具默认不开；你到底开了哪些，以领取回复里的「已开通功能」为准。

## 2. 免费规格

本站只提供免费出图。你的请求如果超出下面的规格，网关会**自动改成合规规格**再出图，不会因此报错：

| 项 | 规则 |
|---|---|
| 每次张数 | 1 张（要求多张会被改成 1 张） |
| 步数 | 不超过 28 步 |
| V4.5 及更早的模型 | 总像素不超过 1024×1024（长宽比随意，宽高取 64 的倍数），超出会等比缩小 |
| V5 | 在 832×1216、1216×832、1024×1024 这三个预设之内；超出会吸附到最接近的预设 |
| 其他 | SMEA 自动关闭；角色参考会被去掉 |

会消耗 Anlas 的功能不开放：图生图 / 局部重绘和 ControlNet 会被直接拒绝（400）。请在客户端里关掉它们再生成。

## 3. 每天的额度（7 点重置）

### 每人上限

| 类型 | 每人每天 | 说明 |
|---|---|---|
| V4.5 及更早的模型 | 上限由算法每天定，首页实时显示（范围 10～300 张） | 每天 7 点后几分钟，算法看昨天全站的用量重算：整体紧张就按大家的需求平分，宽松且有人用满就放宽 25 张 |
| V5 | 首页实时显示（至少 10 张） | 每天 7 点按官方给站长账号的 V5 免费额度恢复速度定出「全站今日共 N 张」，再按前 3 天用过 V5 的人数平分（不到 10 人按 10 人算），当天不再变。每人的上限只是上限，全站先到先得，用的人多时可能抢不到 |
| Anlas | 目前每人 50 点 | 只有 Vibe 会用到：编码一张参考图约 2 点，50 点大约够 25 次；带多张 Vibe 或精确参考的请求会有额外消耗 |

7 点重置后，新的每人额度会在几分钟内更新。每人上限当天一次给足，不再按小时慢慢放；全站的账号总量仍按时段放出，见下面「全站共用的池子」。

### 全站共用的池子（先到先得）

- **账号每日总量**：站长账号一天能出的图是固定的，V4.5 和 V5 合在一起算，而且是按时段平均放出（防止早上被抢光，晚来的人也有份）。
- **V5 全站池**：每天按官方给的 V5 免费额度算出一个「全站今日共 N 张」，所有人合用。
- **Anlas 全站池**：Vibe 等花 Anlas 的操作共用每天一个全站 Anlas 池。

池子是共用的，所以**你自己的额度没用完也可能被拒**（比如「全站今日 V5 额度已用完」）。池子用完后，所有人等到下一个 7 点。想稳妥一点，就别扎堆在高峰时段抢。

### 重置券

站长有时会发「重置券」。在首页使用后，**你本人**今天已用的 V4.5、V5 和 Anlas 都会清零重新算（不会凭空多出全站池）。一张券只能用一次，会过期。

## 4. 限速与排队

| 限制 | 规则 |
|---|---|
| 全站每小时上限 | 按**最近 60 分钟**滚动计算，不是整点重置；满了之后随最早的图滑出窗口逐张恢复，提示里会写大约几分钟后有空位。当前值首页实时显示 |
| 按时段放行 | 账号每日总量不是一次放完；这个时段的份额用完时，网关最多替你等 5 分钟，等不到才返回 429，所以偶尔会感觉请求「卡了一会儿」 |
| 安静时段 | 目前每天凌晨 3:00～7:00 暂停出图，7 点恢复（以首页和状态页显示为准） |
| 上游保护 | 上游限流或连续出错时，全站会暂停出图几分钟，自动恢复 |
| 一次一张 | 同一把 Key 同时只生成 1 张，最多再排 1 张：排着的那张等前一张出完才开始，最多等约 90 秒（超时返回 429）；再多发会被退回 |
| 请求频率 | 每分钟 5 次（生图、Vibe 等；**被拒的请求也算一次**） |
| 写错 Key | 同一个出口 IP 在 10 分钟内累计 20 次无效 Key，会被临时拦截 15 分钟（对有效 Key 没影响） |

## 5. 被拒了怎么办

| 状态码 | 意思 | 该怎么做 |
|---|---|---|
| 401 | 没填 Key，或 Key 写错；Key 已被删除（闲置回收、退群回收）后也是这个提示 | 先检查 Key 是否复制完整；确认已被回收的话，按第 6 节处理 |
| 402 | 额度用完了。常见提示：「今日 V4.5 免费图额度已用完」「今日 V5 额度已用完」「全站今日 V5 额度已用完」「上游账号今日 V5 免费额度已耗尽」「今日 Anlas 额度不足」「全站今日 Vibe / Anlas 额度已抢完」 | 重试没用。V5 用完可以改用 V4.5；其余的等到 7 点 |
| 403 | Key 本身有问题。常见提示：Key 已过期；已被站长停用；全站重置后已失效；被暂停；功能或模型没给你开通 | 按提示处理：过期或被全站重置就去 Discord 重新 `/register`；被暂停就等提示里写的恢复时间；其他的联系站长 |
| 429 | 太快或太忙。常见提示：请求过于频繁；上一张图还没出完；排队的人太多；排队等待超时；全站出图按时段放行、这个时段的份额已用完；最近 60 分钟的出图量已达上限；本站今天的出图总量已达上限；安静时段；上游限流保护中；上游连续出错、暂时停止出图 | **按提示里写的时间再试**，不要连点。客户端有「生图间隔」或「自动重试」的话，把间隔调大、关掉自动重试和批量生成 |
| 400 | 参数不被支持（模型、采样器、角色数、权重写法、图生图等） | 按提示改客户端设置 |
| 502 / 503 | 上游（NovelAI）或站点暂时出问题，比如「V5 额度暂时无法确认」 | 过一会儿再试。提示里写了「未扣积分」的，就没有产生消耗 |

**不要让客户端死循环重试。** 1 小时内同一把 Key 被拒绝累计 60 次，Key 会被自动暂停 1 小时（回 403，提示里写着自动恢复的时间）。「排队的人太多」「全站额度用完」这类不怪你的拒绝不计入。

## 6. Key 的有效期与回收

| 情况 | 会怎样 |
|---|---|
| Key 设了到期日并且到期 | Key 过期，再用 `/register` 领新的（10 月 15 日起新领的 Key 不设到期日） |
| **连续 7 天没有成功生成过图片** | Key 被自动回收，名额释放；之后可以再用 `/register` 领新的 Key。从没生成过图的 Key 从领取那天算起。站长邀请的 Key 不在此列。网关停机维护超过 1 小时的话，计时会从恢复那一刻重新开始 |
| 退出 Discord 服务器 | Key 被回收、名额释放（每天核对一次，不是实时）。重新加入后可以再领 |
| 站长全站重置 | 所有人的旧 Key 失效，用旧 Key 请求会提示去 `/register` 重新领取（站长邀请的 Key 不受影响） |
| 被站长停用 | 提示「该 Key 已被站长停用」，有疑问联系站长 |
| Key 泄露或丢了 | 在 Discord 输入 `/resetkey`，旧 Key 立即失效 |

**一人一把。** Key 仅限本人使用，禁止转售、转借、多人共用，共用或转售会被回收 Key。
