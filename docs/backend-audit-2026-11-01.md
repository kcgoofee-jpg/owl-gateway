## P1 · 身份与凭据

**1. Discord 回调接受另一个浏览器发起的登录。** 登录入口把随机 state 放进 Cookie，但回调匹配到有效签名就放行，即使当前浏览器 Cookie 缺失或不同。攻击者可取得自己尚未兑换的授权回调链接，在有效期内诱导另一浏览器先打开。该浏览器会登录攻击者的成员账号，浏览器标记和来源 IP 也可能被记到攻击者名下。这是成员会话置换，不授予管理权限。应要求发起浏览器证明持有一次性随机值；内置浏览器丢 Cookie 时，重新发起登录，或设计由原浏览器确认的跨浏览器交接。验收用两个独立 Cookie jar，同一回调在错误的 jar 中必须失败且不写登录关联。本地网关连接仅监听回环地址的模拟 Discord 服务，客户端 A 发起授权，客户端 B 完全不带 Cookie 兑换回调，实测返回 307 跳回首页，并收到 owl_member 会话 Cookie。[member.rs L125](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-server/src/routes/member.rs#L125) [member.rs L182](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-server/src/routes/member.rs#L182)

**2. 本地备份生成期间，完整数据库可能被同机普通用户读取。** 快照程序先在输出目录用 SQLite 创建可预测名称的未压缩数据库，再生成权限为 0600 的 gzip。GFS 脚本用普通 mkdir 创建目录。使用合成数据和 umask 022 跑本地 nai-ops，在压缩完成前实测临时库为 **0644**。若父目录可遍历，同机用户可在快照运行时复制包含成员 API Key 的文件。生产目录的实际权限未验证。用 0700 的私有临时目录，排他创建 0600 数据库文件，然后再交 SQLite 写入；同时固定备份目录权限。验收要覆盖正在运行中的文件。[snapshot.rs L25](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-ops/src/snapshot.rs#L25) [snapshot.rs L151](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-ops/src/snapshot.rs#L151) [naigate-backup L6](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/deploy/v3/ops/naigate-backup#L6)

**3. 更换上游 Token 时，后台返回失败也可能已经改变了出图所用的凭据。** 替换先修改内存池，再迁移 SQLite 记录，最后保存令牌文件。中间任一步失败，服务可能继续用新 Token，管理员按旧 ID 重试可能收到 404，重启又按旧文件加载。新增和删除走相同的先内存后落盘顺序。并发管理操作还共用固定的 .tmp 文件名。应把变更串行化，建立可恢复的持久状态，再发布内存快照。用写入失败、并发替换和中途重启做验收，核对运行池、重启池与账号计数。源码追踪。[upstream.rs L295](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-server/src/routes/admin/ops/upstream.rs#L295) [upstream.rs L327](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-server/src/routes/admin/ops/upstream.rs#L327) [token_store.rs L47](https://github.com/kcgoofee-jpg/owl-gateway/blob/bdcd9fc9fd3ee38fc43964ffe007636adb04d450/crates/gate-upstream/src/token_store.rs#L47)

## P2 · 计费、限流与可用性

**4.
