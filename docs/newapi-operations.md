# OWL / New API 运维约定

2026-11-02，按站长授权开放注册并持续维护。对外公告须署名“Codex 运维助手，受站长委托”。

## 开放与额度

- OWL 原生领取条件：`claim_rules.open=true`、`max_users=0`。0 在注册服务中表示无限人数，不移除身份组、单账号、频率和反滥用条件。
- New API 自助公开注册保持关闭；由 `owl-ai-account.service` 自动发号。当前有效生图成员，或已成功登录且最近30天通过当前身份组条件的成员可开通。不要求先持有生图 Key。
- 头像菜单通过 OWL `/public/me` 验证当前签名会话及 Key 指纹；浏览器标记 `owl_bid` 不能作为身份凭据。
- 首次账号余额 $5；签到按北京时间自然日每账号一次，随机 $2–$5、累计到钱包。500000 quota = $1。重复登录/换浏览器/换生图 Key 不再送初始余额。
- 账号桥每60秒幂等补齐，每批只读取一次成员资格集合，交互式发号仍现查资格。既有停用账号不被循环自动解封。
- 火山渠道9只提供 `doubao-seed-2.1-lite` 与 `doubao-embedding-vision`；高级自定义58继续使用 Coding Plan 聊天与 embeddings 路由。渠道4的带前缀 DeepSeek 属于另一上游。
- 站内钱包不等于上游余额；禁止为了恢复可用性自动充值、提高上游预算或切到新的按量收费端点。Coding Plan 的服务商适用范围另受官方规则约束。

## 额度保护与巡检

Codex 自动化 `opus-5-5` 为持续运维监控，保持运行。无可操作变化时安静；重要故障、修复、额度临界或必须站长介入时通知。

- Claude 官方活动额度、有效期或月预算耗尽导致停止时，停用公益渠道7，并从私有渠道6移除同一 Opus 模型；保留密钥及其他模型，不提高预算。
- zcode-api 主实例供奶妹使用（宿主机回环 8090；本机 8080 另有用途）。以 `/quota` 的相应 `balances` 为准；没有 coding plan 不表示活动 token 额度耗尽。GLM-5.3-Flash 剩余≤100万 token 或到期无续额时，停 New API 共享渠道2，优先奶妹；不自动恢复共享渠道，不停 zcode 服务。
- 不做收费生成巡检。模型列表200仅证明鉴权和路由；结合真实成功/错误日志、官方用量判断生成状态。
- 检查网关/机器人容器、心跳、账号桥、zcode、注册设置、签到设置、磁盘/内存、备份新鲜度、设备节点与 cgroup。
- `/dev/null` 必须是字符设备1:3，不能是普通文件。2026-11-02曾发现多个基础设备节点缺失，已恢复；日志轮转及 zcode 版本检查随后通过。异常现场保留在服务器受保护备份目录，不能读取或公开旧 null 的内容。

- 目录700、文件600；保留14天的自动备份，手工事故与发布备份单独保留。
- `deploy/v3/ops/nightly_backup.sh` 沿用既有加密S3链路，新增 `newapi.db.gz` 与 `newapi-config.tar.gz`，包括账号桥派生秘密和启动配置。密钥/口令只保留在服务器受保护位置，不进仓库、不展示。
- 2026-11-02现场验证：上传后重新下载S3密文、解密至隔离目录；两个 SQLite quick_check 通过，注册/渠道配置吻合，账号桥恢复配置齐备，878个工作台文件的 SHA256 全部吻合。没有启动恢复副本或重放上游请求；这证明备份下载、解密及数据/文件完整性，不等于已演练生产服务切换。
- 恢复前先进入维护并备份现状，排空请求后停止写入服务；在隔离目录校验数据库与文件，再按既有恢复流程恢复数据、配置及权限。需要恢复 OWL 数据库时同时核对支付结算，保留 uncertain 状态，不重放已发出的上游请求。完成无费用健康/鉴权检查后再开放。
